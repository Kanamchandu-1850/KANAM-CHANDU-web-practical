calc(), min(), max(), and clamp() Functions

Modern CSS Sizing Functions

These functions let width/font-size adapt responsively without media queries. Try resizing the browser window.

width: calc(100% - 80px)
width: min(80%, 300px)
width: max(40%, 250px)
font-size: clamp(1rem, 2vw + 0.5rem, 2rem) — this text scales with the viewport within limits.
