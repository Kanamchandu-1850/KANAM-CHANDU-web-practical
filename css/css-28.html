em, rem, vw, vh & Percentage Units

CSS Unit Comparison

em is relative to the parent's font-size, rem to the root's, vw/vh to the viewport, and % to the parent value.

1.5em text (relative to parent font-size)

1.5rem text (relative to root/html font-size)

4vw text (scales with viewport width — resize window to see it change)

10vh tall box (10% of viewport height)

150% text (relative to parent's computed font-size)
